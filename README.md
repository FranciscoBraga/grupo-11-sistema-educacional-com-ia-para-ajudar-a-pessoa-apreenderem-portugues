# Aprende Português 📚

Plataforma com IA que ensina português **sem dar resposta pronta**: o tutor faz perguntas para o aluno descobrir o erro sozinho (método socrático).

## Requisitos

- Python 3
- Conta OpenAI

## Executar

```
pip install flask openai
export OPENAI_API_KEY=...
python app.py
```

Acesse http://localhost:5000

## Recursos

- Exercícios de crase, concordância, acentuação e pontuação (mais de 500 exercícios)
- Tutor socrático com IA
- Correção de redação no padrão ENEM
- Níveis básico, médio e avançado (o sistema adapta sozinho)
- Gamificação com XP (nunca perde pontos, para não desmotivar)

## Banco

O banco é populado automaticamente uma vez.
